1. Introduction

This minor report documents the initial phase of the "Gym Akhada" system development. The focus during this phase was strictly on establishing a solid foundation, which included database design, server configuration, and custom user authentication without relying on pre-built ASP.NET Identity scaffolding.

2. Objectives Achieved

  • Design and implementation of the SQL Server Database using Entity Framework Core Code-First Migrations.
  • Creation of the core `AppUser` and `GymMember` entity relationship models.
  • Implementation of a custom Cookie-Authentication controller.
  • Development of a responsive, Dark-Themed UI baseline using Bootstrap 5.

3. Server Handling & Backend Logic

The backend was architected using C# and ASP.NET Core 8.0. A primary challenge was ensuring that the mapping between a Login ID (`AppUser`) and a Physical Member (`GymMember`) was mathematically secure. This was achieved using Nullable Foreign Keys, allowing Admin accounts to exist without a physical gym profile, while forcing all regular users to have mapped profiles.

Password security was handled using a custom SHA-256 hashing algorithm implemented directly in the `AccountController`. This ensured that plain-text passwords never touch the database.

4. Conclusion of Minor Phase

The completion of the core authentication, routing, and database modules provided a highly stable platform. This architectural stability was crucial for the seamless integration of advanced APIs (Twilio/SMTP) and complex tournament business logic in the major phase.
